
## 🐳 Despliegue con Docker Desarrollo masivo

```bash
# Construye todas las imágenes
docker compose build

# (Opcional) Etiqueta y sube las imágenes
docker compose push

# Levanta todos los contenedores
docker compose up -d

# detener todo
docker compose down

```
